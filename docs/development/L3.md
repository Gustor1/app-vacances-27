Il vérifie que le code n’a pas changé pendant les contrôles. L’empreinte exclut Markdown/docs et fichiers ignorés ; une copie complète séparée conserve aussi la documentation finale. Les tests unitaires injectent un code 17 et une exception, vérifient l’arrêt, les contrôles non exécutés et le code non nul.

Les routes interceptées répondent avant DNS ; le loopback reste autorisé. Les captures des smokes vont dans le dossier temporaire, pas sur les anciennes captures du dépôt.
