# Retrouver mes données

1. Reviens sur **la même adresse**, dans **le même navigateur et le même compte**. Safari, Chrome et une autre adresse peuvent avoir des copies différentes.
2. Hors ligne, ouvre un carnet déjà téléchargé. Dans « Mon carnet pratique », touche **Vérifier** : le contrôle relit le carnet enregistré et les ressources de l’application. Après une modification, vérifie de nouveau avant le départ.
3. **Enregistré sur cet appareil** confirme la copie locale. **En attente d’envoi** signifie que les changements attendent un échange. **Synchronisé** indique un échange confirmé. Une connexion Internet ou un cache prêt ne constitue pas une sauvegarde externe.
4. Si l’enregistrement échoue, **exporte le carnet affiché avant de fermer**. Si un conflit apparaît, conserve les deux sources et compare les valeurs avant de choisir. Les copies de récupération servent à retrouver un état précédent.
5. Avant de vider les données du navigateur, supprimer l’application ou changer d’appareil, télécharge une **sauvegarde complète**, garde-la sur un autre support et vérifie sa restauration dans un espace distinct. Une déconnexion ne transfère pas les envois encore en attente.
6. Les cartes de rues, les liens et les couvertures externes demandent Internet. Les documents joints sous forme de texte dans le carnet restent dans la copie téléchargée ; un lien vers un document distant exige toujours Internet.

Un accès retiré bloque les échanges futurs. Il ne garantit pas l’effacement des copies, exports ou captures déjà téléchargés.
